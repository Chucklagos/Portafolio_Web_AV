# Portafolio_Web_AV

Portafolio profesional web de **Allan Fernando Velasquez Corea**, Ingeniero Químico Industrial | Procesos, Producción y Calidad.

Portafolio moderno y corporativo (HTML5, CSS3, JavaScript + Bootstrap Icons via CDN), con:

- Hero profesional con foto, CTA y información de contacto.
- Secciones: Sobre mí, Áreas de especialización, Experiencia profesional (timeline), Formación académica, Competencias técnicas, Formación complementaria, Contacto profesional, Descargar CV.
- Datos estructurados (Schema.org: Person), Open Graph, meta tags SEO optimizados para mercado español.
- Animaciones sutiles respetando `prefers-reduced-motion`.
- Página responsive (móvil/tablet/desktop).

Ficheros:

- `index.html` — página principal.
- `style.css` — estilos (paleta azul oscuro, Space Grotesk + Inter).
- `script.js` — menú móvil, scroll smooth, reveal en scroll.
- `favicon.svg`, `sitemap.xml`, `robots.txt`.

Cómo verlo:

```bash
python3 -m http.server 8000
# abrir http://127.0.0.1:8000/index.html
```

Verificación de sintaxis:

```bash
node --check script.js
# parser de sintaxis de HTML y balance de etiquetas
```
